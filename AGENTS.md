# Guia para IA — Atividade5-EdN

Exercícios Python de gorjeta, palíndromo, desconto e idade em dias.

1. Ler cada enunciado antes de alterar o algoritmo.
2. Não trocar fórmulas e formato de saída exigidos pela atividade.
3. Preservar nomes em português e arquivos: 1/gorjeta.py, 2/palindromo.py, 3/desconto.py, 4/idade_em_dias.py.
4. Não adicionar dependências externas sem necessidade.
5. Evitar credenciais e dados reais em código ou logs.
6. Testar sintaxe e comparar entradas/saídas para cada script; testes de documentação não validam comportamento.

Atenção: Exercícios didáticos; validar resultados contra os enunciados originais.
